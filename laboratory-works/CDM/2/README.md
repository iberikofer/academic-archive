# 📑 Laboratory Work #2: Binary Relations & Properties

> **Course:** Computer & Discrete Mathematics (CDM)  
> **Institution:** Vinnytsia National Technical University (VNTU)  
> **Language:** English

---

## 🎯 Goal

Study binary relations, matrix representation methods, directed graph representations, and algorithms for checking mathematical relation properties (reflexivity, symmetry, anti-symmetry, transitivity).

---

## 💻 Implementation & Code Structure

The application [`main.py`](./main.py) is implemented in Python.

---

## 🚀 How to Run

1. Install prerequisites and run the application:

```bash
pip install networkx matplotlib
python main.py
```
