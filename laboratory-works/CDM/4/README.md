# 📑 Laboratory Work #4: Minimization of Boolean Logic Functions

> **Course:** Computer & Discrete Mathematics (CDM)  
> **Institution:** Vinnytsia National Technical University (VNTU)  
> **Language:** English

---

## 🎯 Goal

Study Boolean algebra minimization techniques, construct Disjunctive Normal Forms (DNF), and perform 4-variable logic optimization using Karnaugh Maps (K-maps) and SymPy logic engines.

---

## 💻 Implementation & Code Structure

The application [`main.py`](./main.py) is implemented in Python.

---

## 🚀 How to Run

1. Install prerequisites and run the application:

```bash
pip install sympy matplotlib
python main.py
```
