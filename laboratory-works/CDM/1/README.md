# 📑 Laboratory Work #1: Sets & Basic Operations

> **Course:** Computer & Discrete Mathematics (CDM)  
> **Institution:** Vinnytsia National Technical University (VNTU)  
> **Language:** English

---

## 🎯 Goal

Master the basic concepts of set theory, methods of set definition, power set creation (2^A), and set operations (union, intersection, difference, symmetric difference) with interactive Venn diagram visualizations.

---

## 💻 Implementation & Code Structure

The application [`main.py`](./main.py) is implemented in Python.

---

## 🚀 How to Run

1. Install prerequisites and run the application:

```bash
pip install matplotlib matplotlib-venn
python main.py
```
