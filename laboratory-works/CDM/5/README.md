# 📑 Laboratory Work #5: Fundamentals of Graph Theory

> **Course:** Computer & Discrete Mathematics (CDM)  
> **Institution:** Vinnytsia National Technical University (VNTU)  
> **Language:** English

---

## 🎯 Goal

Learn graph theory fundamentals, graph representation matrices, calculate vertex degrees, analyze connectivity, and find routes between vertices (v1 to v7) in directed graphs.

---

## 💻 Implementation & Code Structure

The application [`main.py`](./main.py) is implemented in Python.

---

## 🚀 How to Run

1. Install prerequisites and run the application:

```bash
pip install networkx matplotlib
python main.py
```
