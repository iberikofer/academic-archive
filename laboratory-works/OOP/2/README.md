# 📑 Laboratory Work #2

> **Course:** Object-Oriented Programming (OOP)  
> **Institution:** Vinnytsia National Technical University (VNTU)  
> **Language:** English

---

## 🎯 Goal

Design a domain class `Athlete` implementing fundamental OOP concepts: encapsulation, constructors, static and non-static initialization blocks, constructor delegation (`this(...)`), instance methods (`train()`, `eat()`, `rest()`, `takeSelfie()`), and Java's `equals()` / `hashCode()` contract.
