# 📑 Laboratory Work #5

> **Course:** Object-Oriented Programming (OOP)  
> **Institution:** Vinnytsia National Technical University (VNTU)

## 🎯 Goal

Extend the JavaFX `GymWorld` GUI application with class inheritance hierarchies (`PowerLifter`, `GymBoss`), real-time minimap radar navigation (`Minimap`), and multi-criteria search and filter dialogs (`SearchDialog`, `FilterDialog`).
