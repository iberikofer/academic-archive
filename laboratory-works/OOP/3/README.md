> **Course:** Object-Oriented Programming (OOP)

## 🎯 Goal

Implement object composition and array management for `Athlete`, `Equipment`, and `TrainingZone` classes featuring deep copying (`Cloneable`), natural and custom sorting (`Comparable` and `Comparator`), binary search algorithms, team competitions, and zone interactions.
