# 📑 Laboratory Work #4

> **Course:** Human-Computer Interaction (HCI)  
> **Institution:** Vinnytsia National Technical University (VNTU)  
> **Language:** English

---

## 🎯 Goal

Build a modern, single-page web application (SPA) in React 19 and Vite implementing an ASCII CyberShop store with modular functional components, client-side routing views, state persistence in `localStorage`, live search filtering, user authentication, interactive cart management, and admin dashboard.

## 🚀 How to Run

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

3. Build production bundle:

```bash
npm run build
```
