# 📑 Laboratory Work #3

> **Course:** Human-Computer Interaction (HCI)  
> **Institution:** Vinnytsia National Technical University (VNTU)  
> **Language:** English

---

## 🎯 Goal

Create a desktop GUI application using C# Windows Forms simulating an ASCII CyberShop store with user authentication, product search, cart management, checkout, and password-protected admin dashboard for adding products and filtering order history.

---
