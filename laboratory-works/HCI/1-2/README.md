# 📑 Laboratory Work #1-2

> **Course:** Human-Computer Interaction (HCI)  
> **Institution:** Vinnytsia National Technical University (VNTU)  
> **Language:** English

---

## 🎯 Goal

Develop a C++ command-line interface emulator simulating MS-DOS system commands (`MODE` for system console and serial port configuration, `ERA` for file deletion, and `PIP` for binary file copying).

---

## 💻 Code & Resources

- **Main Code:** [`main.cpp`](./main.cpp)
- **Course Guidelines:** [HCI Guidelines (PDF)](../ЛР_Людино-Машинна_Взаємодія_Методичні_вказівки.pdf)

---

## 🚀 How to Run

1. Compile C++ source code:

```bash
g++ -O2 main.cpp -o main
```

2. Execute binary:

```bash
./main
```
